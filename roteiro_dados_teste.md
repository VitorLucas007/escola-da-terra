# Roteiro de dados de teste

Dois participantes fictícios, para cobrir os caminhos "sim" e "não" dos formulários.
Os valores entre aspas são os `value` exatos dos campos. Onde não há aspas, digite livremente.

Ordem dos formulários (campo `progresso_participante`):
1. Sobre o cursista → 2. Família → 3. Formação escolar → 4. Carreira → 5. Exercício da profissão → 6. Condição de estudo → 7. Vida geral

Como começar: entre como pesquisador, abra o dashboard, escolha "novo participante" e digite o telefone do participante. Se o telefone já existir, o sistema retoma do ponto em que ele parou.

### 4. Conferir tudo de um participante

Troque o `1` pelo `id_participante` que apareceu em `UserParticipante`.

```sql
SELECT u.id_participante, u.telefone, u.progresso_participante,
       c.id_sobre_cursista, c.ano_nascimento, c.sexo, c.estado_civil
FROM UserParticipante u
LEFT JOIN SobreCursista c ON c.participante_id = u.id_participante
WHERE u.id_participante = 1;
```

Os nomes `id_sobre_cursista` e similares são os mais prováveis, mas eu não vi o schema. Se alguma coluna de chave primária tiver outro nome, use `SELECT *` na tabela e ajuste.

## Pontos de risco encontrados nos formulários

Se algum desses falhar, a causa provável é um valor do formulário que não bate com o ENUM do banco:

- **Família, acompanhante do filho menor:** a opção "Com uma babá ou cuidadora" envia `Com uma babá ou cuidadora'` (com aspas simples sobrando). Evitada no roteiro.
- **Família, escolaridade das avós:** "Ensino médio" (com acento) em `escolaridade_avo_fem_*`, mas "Ensino medio" (sem acento) no avô e nos genitores. Evitado no roteiro; vale testar depois.
- **Carreira, 2ª escola em diante:** o modelo clonado usa "Ensino media", "Educacao especial" e "Escola de Comunidades Quilombola", diferentes da 1ª escola ("Ensino Medio", "Educacao Especial", "Escola de Comunidades Quilombolas"). Vale testar adicionando uma segunda escola.
- **Família, irmãos:** a opção Sim de "habita mesma localidade" envia `1'`. O PHP converte para 1, então funciona por acaso.
